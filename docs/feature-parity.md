# Feature parity

The redesign keeps the original product's useful workflows while reducing the navigation from a long feature list to five destinations.

| Original HealthCore feature | Mettlefield location | Current behavior |
| --- | --- | --- |
| Dashboard | Today | Daily calorie balance, macros, water, sleep, training status, recent food, habits, and meal-idea shortcut |
| Food Log | Log, Diary | Search across 719 retained common foods, one-tap catalog logging, manual entry, macro totals, deletion, water, weight, and sleep records |
| Nutrition Charts | Log, Nutrition | Calories by meal, macro progress, seven-day logging pattern, and frequent foods |
| Meal Ideas | Log, Food ideas | All 52 original meal ideas, goal filters, search, shopping lists, instructions, and one-step logging |
| Workouts | Train, Workout | Searchable illustrated exercise library, movement details, sets, weights, reps, prior-set context, rest timer, finish summary, and recent session history |
| Workout plans | Train, Plans | Starter templates, editable custom movement lists, deletion, active-plan selection, and one-step launch into a live session |
| Strength PRs | Train, Strength PRs | Manual records and estimated one-rep maxes derived from completed sets |
| Cardio | Train, Cardio | Manual activity entry and Garmin-imported activities |
| Weight | Log and Trends | Entry in the daily log and a longer-term trend chart |
| Sleep | Log and Trends, Recovery | Entry, seven-night context, consistency, and target hit rate |
| Daily habits | Today and Trends, Recovery | Daily toggles, custom habits, and weekly completion |
| Muscle Map | Trends, Muscle map | Programmatic muscle-group volume based on completed sets |
| Weekly Report | Trends, Weekly report | Nutrition, training, cardio, habits, sleep, and print support |
| Garmin Import | Settings | Local CSV and JSON import with duplicate protection |
| Goal settings | Settings | Goal type, nutrition, water, sleep, and unit settings |
| Data export | Settings | Strictly validated JSON backup and restore; reset downloads a backup before typed confirmation |
| AI Coach | Trends, Check-in | Replaced with a deterministic, record-based review that makes no diagnosis |

Removed from the new product:

- Decorative avatars and generated characters
- Hosted or user-key chat integrations
- Food-photo estimates that could imply more accuracy than they provide
- Strength percentile claims without a maintained, defensible reference dataset

These removals narrow the product to tools that can be verified and explained clearly.
